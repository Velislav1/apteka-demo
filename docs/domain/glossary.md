# Речник

Един термин = едно име в кода. Интерфейсът е на български, кодът е на английски.

| Български | В кода | Значение |
|---|---|---|
| Стока | `Product` | Лекарство или друг артикул |
| Режим на отпускане | `DispensingMode` | `OverTheCounter` (без рецепта), `Prescription` (по лекарско), `Narcotic` (упойващо, специална рецепта) |
| Мярка за продажба | `Product.DefaultSaleUnitId` | Мярката, която касата предлага първа |
| Код по НЗОК | `Product.NhifCode` | Кодът на стоката в списъка на НЗОК |
| Производител | `Manufacturer` | Справочник в Catalog |
| Група | `ProductGroup` | Справочник в Catalog (по ATC анатомична група в seed) |
| Рафт | `Shelf` | Място в аптеката (рафт, хладилник, сейф) |
| Мярка | `ProductUnit` | Кутия, блистер, таблетка; `Factor` спрямо най-малката мярка |
| Най-малка мярка | `BaseUnit` | Мярката с `Factor = 1`; всички количества се пазят в нея |
| Доставчик | `Supplier` | Фьоникс, Стинг, Софарма и др. |
| Доставка / складова разписка | `Delivery`, `DeliveryLine` | Документ за получена стока |
| Партида | `Batch` | Номер на партида + срок на годност + цени |
| Движение | `StockMovement` | +/- количество за партида (доставка, продажба, брак, корекция) |
| Свободна продажба | `Sale` с `SaleType.Retail` | Продажба без рецепта по НЗОК |
| Продажба по НЗОК | `SaleType.Nhif` | По-късно, не в демото |
| Склад | `StockType.Retail` / `StockType.Nhif` | Наличността по НЗОК се води отделно |
| Сторно | `Reversal` | Обратна операция; нищо не се изтрива |
| Модул | `Catalog`, `Purchasing`, `Inventory`, `Sales`, `Identity`, `Audit` | Самостоятелна област с 4 проекта и собствена DB схема |
| Договор на модул | `Apteka.<Module>.Contracts` | Единственото, което другите модули виждат |
| Пари | `Money` | Сума в евро, 2 знака, закръгляне встрани от нулата |
| Количество | `Quantity` | Цяло неотрицателно число в най-малка мярка |
