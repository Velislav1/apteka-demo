# Речник

Един термин = едно име в кода. Интерфейсът е на български, кодът е на английски.

| Български | В кода | Значение |
|---|---|---|
| Стока | `Product` | Лекарство или друг артикул |
| Режим на отпускане | `DispensingMode` | `OverTheCounter` (без рецепта), `Prescription` (по лекарско), `Narcotic` (упойващо, специална рецепта) |
| Мярка за продажба | `Product.DefaultSaleUnitId` | Мярката, която касата предлага първа |
| Код по НЗОК | `Product.NhifCode` | Кодът на стоката в списъка на НЗОК |
| Код на стоката | `Product.Code` | Вътрешен номер (1, 2, 3…), по който се търси на касата и в доставката |
| Наименование лат. / генерика | `Product.LatinName`, `Product.GenericName` | Име на латиница; международно непатентно име |
| Мин. / макс. запас | `Product.MinStock`, `Product.MaxStock` | В най-малка мярка |
| Търговска надценка | `MarkupPercent` | На стоката, иначе на групата, иначе 25 % |
| Производител | `Manufacturer` | Справочник в Catalog |
| Група | `ProductGroup` | Справочник в Catalog (по ATC анатомична група в seed) |
| Рафт | `Shelf` | Място в аптеката (рафт, хладилник, сейф) |
| Мярка | `ProductUnit` | Кутия, блистер, таблетка; `Factor` спрямо най-малката мярка |
| Най-малка мярка | `BaseUnit` | Мярката с `Factor = 1`; всички количества се пазят в нея |
| Доставчик | `Supplier` | Фьоникс, Стинг, Софарма и др. |
| Доставка / складова разписка | `Delivery`, `DeliveryLine` | Документ за получена стока |
| № на складова разписка | `Delivery.Number` | Пореден номер на доставката |
| Дни за плащане / падеж | `Delivery.PaymentTermDays`, `Delivery.DueDate` | По подразбиране от доставчика |
| Цена ТЕ / Отстъпка ТЕ | `DeliveryLine.UnitPurchasePrice`, `SupplierDiscountPercent` | Цена и отстъпка от търговеца на едро |
| Покупна цена | `DeliveryLine.NetUnitPurchasePrice` | Цена ТЕ минус отстъпката; влиза в партидата |
| Партида | `Batch` | Номер на партида + срок на годност + цени |
| Движение | `StockMovement` | +/- количество за партида (доставка, продажба, брак, корекция) |
| Свободна продажба | `Sale` с `SaleType.Retail` | Продажба без рецепта по НЗОК |
| Продажба по НЗОК | `SaleType.Nhif` | По-късно, не в демото |
| Склад | `StockType.Retail` / `StockType.Nhif` | Наличността по НЗОК се води отделно |
| Директна продажба | `Sale` с `SaleType.Retail` (екранът „Каса“) | Името на свободната продажба в Аптека Експерт |
| ТО / Обща ТО | `SaleLine.DiscountPercent` | Търговска отстъпка на ред; общата (`%10` на касата) се дава на всички редове |
| Активно вещество | `Product.ActiveSubstance` | Търси се и по него |
| Бракуване | `WriteOff`, `WriteOffLine` | Изписване на негодна стока от избрана партида (движение `WriteOff`) |
| Корекционна складова разписка | `DeliveryCorrection` | ± по редовете на приключена доставка (кредитно/дебитно известие) |
| Инвентаризация / протокол | `Stocktaking`, `StocktakingLine` | Преброяване по партиди; разликите стават движения `Correction` |
| По документи / Намерено | `ExpectedQuantity` / `CountedQuantity` | Наличност при започване / преброено количество |
| Клиент / пациент | `Customer` | С ЕГН, код, телефон; избира се на касата с F2 |
| ЕГН | `Customer.Egn`, `Egn` | 10 цифри, дата + контролна цифра; само измислени в демото |
| Корекция на продажба / кредитно известие | `SaleReturn` | Връщане на част от продажба (винаги минус); парите и стоката се връщат |
| Сторно | `Reversal` | Обратна операция; нищо не се изтрива |
| Модул | `Catalog`, `Purchasing`, `Inventory`, `Sales`, `Identity`, `Audit` | Самостоятелна област с 4 проекта и собствена DB схема |
| Договор на модул | `Apteka.<Module>.Contracts` | Единственото, което другите модули виждат |
| Пари | `Money` | Сума в евро, 2 знака, закръгляне встрани от нулата |
| Количество | `Quantity` | Цяло неотрицателно число в най-малка мярка |
